Grid lines & editor chrome — before / after

This theme's slides use 28pt body text. The grid editing lines were sized with the theme's line-thickness setting, which grows with text size — so they drew ~2.4× too thick (4.8px instead of 2px on screen). Now they're fixed screen-size, like the rest of the selection chrome.

Measured on the Course Agenda card: grid outline 4.8px → 2.15px, outline gap from text 9.3px → 4.3px, spacer size badge text 32px → 14px. Themed dividers (where the line is part of the design) are unchanged.
