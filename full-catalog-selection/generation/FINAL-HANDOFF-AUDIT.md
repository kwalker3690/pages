## What the experiment supports

The evidence supports **keeping both routes and making original authorship a serious option**. Original art direction can create brief-specific explanatory systems, not just palette changes: the Hegel seminar transformation and Kiều rhyme chain are tangible examples. Topic overlap alone does not prove that a library theme satisfies explicit audience and style requirements. Conversely, the completed judgments already include stable library preferences for school ozone and premium wellness; the original route is not a universal upgrade.

At the judgment snapshot, adult ozone, children’s history, salon, dark conference, and handover prefer original in both orders; school ozone and wellness prefer library in both orders. Pirate and QBR reverse with presentation order and must be inconclusive. Auth has only one completed judgment in this snapshot; Hegel, Kiều, media history, and agriculture are not included in this snapshot aggregate. Use the final report’s completed table instead of these interim counts.

**Routing conclusions remain exploratory.** A prompt-sensitive/stochastic selector needs repeated trials of the same brief/catalog before claiming calibrated confidence or a reliable fallback threshold. A hand-picked threshold justified after viewing these outputs is not independent validation. The pirate requirement to feel original is also an explicit user preference, which an automated preference judge cannot override.

**This is an end-to-end authoring treatment comparison, not an isolated theme experiment.** Original receives custom art direction, themes, layout ideas and generated imagery; library works inside a different visual system. Both arms have iterative repairs, with differing repair needs. The resulting finals demonstrate achievable quality after intervention, not first-pass reliability, generation latency, cost parity, or a pure causal effect of template choice. AB/BA detects some order sensitivity but is not two independent human judges; the pirate negation hallucination is direct evidence that automated hard-failure allegations need source/PNG adjudication. Several winners are only “occasional” wow. Prefer a human blind review plus repeat selection/generation runs before productizing routing rules.
