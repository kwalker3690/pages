Golden Template Pipeline Report

Generating slide decks from text prompts using a new "golden template" system | 2026-04-27

How It Works

What is this report?

Gamma generates slide decks from a text prompt. A user types something like "Cybersecurity trends 2026" and the system produces a complete, styled presentation. This report shows the output of running that pipeline end-to-end with a new approach called golden templates.

The Pipeline: Two Stages

The deck generation pipeline has two main stages:

User Prompt: "Cybersecurity trends 2026" | [Stage 1: Gen3] Plans the deck structure + writes an outline | - Decides how many cards (slides) | - Assigns each card a role (title, content, breather, closing, sources) | - Writes instructions for each card's content | [Stage 2: GenDeck] Converts the outline into visual card markup | - Matches each card to a golden template | - AI writes GML (card markup) based on the template | - One AI call per card (was previously two) | [Rendering] Screenshots + quality checks - Cards rendered as images - Automated graders score the output

What are Guides? (Design Styles)

A "guide" is a design style that controls how decks look. This report tests three guides:

  • Consultant — Data-heavy, chart-rich slides with 150-250 words per card. Think McKinsey or BCG strategy decks: bar charts, key metrics, columnar layouts. Dense and analytical.
  • Minimal — Image-forward, atmospheric, only 15-40 words per card. The photo IS the design. Full-bleed background images with sparse, elegant text overlays.
  • Swiss — Editorial typography, high-contrast, strict grid structure. Inspired by Swiss/International Typographic Style: bold headings, structured columns, horizontal rules as dividers. Almost no smart-layouts — the grid does the work.

What are Golden Templates?

Previously, the AI received abstract rules like "use a two-column layout with a chart." With golden templates, we instead show the AI a complete real card from a hand-crafted "golden" example deck that we know looks good, and say "make something like this but about [new topic]."

This is like remix — the AI sees what good looks like and reproduces the pattern. The golden examples contain real text content, real data, real charts. They are complete, polished cards extracted from curated reference decks.

There are also hand-authored templates — manually-written structural skeletons with placeholder content like <!-- 2-3 sentences -->. These define layout structure but not content, and are used as a fallback when no golden example is a strong match.

How Template Matching Works

Each card in the outline is matched to the best golden template based on a scoring system:

  • cardRole — Does the template's role match? (title-to-title, content-to-content, closing-to-closing) This is the strongest signal.
  • imageLayout — Does the image placement match? (blank-to-blank, behind-to-behind) Important for visual consistency.
  • density — Does the word density match? (sparse-to-sparse, dense-to-dense)
  • variety penalty — Has this template already been used? Penalizes reusing the same template across multiple cards.

The template with the highest total score is selected for each card.

6-7
Strong match — role + layout + density all aligned
3-5
Moderate match — role matched, but layout or density didn't
2
Weak match — best available, but not ideal

What are the Quality Checks (Grader Scores)?

After the deck is generated and rendered, automated quality checks evaluate the output. There are three types:

  • Code graders — Parse the GML (card markup) and check structural rules. Is the word count in the target range? Are there enough charts? Are columns balanced?
  • Vision graders — Look at screenshots of the rendered cards and evaluate visual quality. Is there wasted space? Alignment issues? Column balance problems?
  • Model graders — An AI reads the text content and evaluates quality: Are the titles compelling? Is there a narrative arc? Is there layout variety?

Each grader returns a 0-1 score and a pass/fail verdict. The pass rate across all graders is the headline quality metric.

Key wins: The golden template approach produces cards in a single AI call instead of two (previously: one call to plan the layout, one to write the markup). This makes generation ~30% faster. The Consultant guide shows excellent template coverage (89% golden templates) and strong structural quality.

Remaining gaps: Minimal needs more behind-image cards and tighter word counts. Swiss needs golden examples (currently using only hand-authored templates), plus structural features like horizontal rules and stacked column grids.

Key Observations

Consultant is the strongest performer at 85% pass rate. Golden templates from the "breach" deck dominate (5/9 cards), producing consistent chart+column+metrics layouts. The two failures are: (1) word density — 3 cards fall below the 150-word minimum (card 4: 101w, card 6: 136w, card 8: 76w), and (2) alignment consistency — mixed alignment in some visual zones. A notable gap: every column layout uses the identical [42,58] split, which the structural fidelity grader flagged.

Minimal has the most room to improve at 50% pass rate. The core problem: not enough behind-image cards (3/9 vs the 50% minimum). The minimal aesthetic requires the photograph to BE the design, but most cards use blank layouts with inline images or smart-layouts instead. Additionally, content cards are too wordy for minimal (3 cards exceed 50 words when the target is 15-40). The positives: solidBoxes-only smart-layout restraint is excellent, and background color alternation works well.

Swiss has the most graders (28 — reflecting how specific the Swiss design language is) and the most failures (10). Key gaps: zero horizontal rules (a signature Swiss structural element), no accent colors in headings, no typographic statement cards (where bold type IS the design), no stacked column patterns, and the closing card is a Sources page rather than a dramatic typographic ending. However, the prose quality, column split variety (4 distinct patterns), text-color hierarchy, and smart-layout restraint all pass. The biggest improvement opportunity: creating golden example decks for Swiss, since it currently uses only hand-authored skeletons.
