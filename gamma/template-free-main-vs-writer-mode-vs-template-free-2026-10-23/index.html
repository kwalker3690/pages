Main vs branch A vs branch B

Same 5 prompts, Standard plan, local app, one deck each. The three rows per topic:

  • M Main today: A library template is picked for the deck. The writer gets the template’s styles AND its example slides, and builds each slide by adapting one of those example layouts.
  • A Branch A: Jon’s writer mode: Same library template pick as main, but the template is used only for its styles: colors, fonts, type sizes, and stylesheet decorations. None of its example slides reach the writer, which invents every slide layout itself.
  • B Branch B: template-free look: No library template at all. A look is designed for the deck and painted as 3 look boards (openers and sections; data and structure; picture and text); the theme is written from the boards. The writer works in Jon’s mode (no example slides) and gets the 3 boards, a slide-by-slide plan naming which board panel each slide follows, the look notes, and the composition guide.

The short version: M and A start from the same library template. M copies the template’s example layouts; A keeps only the template’s styles and makes its own layouts. B has no template: it designs a look and makes its own layouts guided by the look boards. Open “Look book” under any deck to see what it was working from.
